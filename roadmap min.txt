## 📅 Weekly Sprint Plan (12 Weeks)

### Week 1–2: **Frontend Foundations**
- Goal: Ship portfolio skeleton with Next.js + Tailwind  
- Daily checkpoints:  
  - Day 1: Setup Node.js + Next.js starter, GitHub repo  
  - Day 2: CSS selectors, flexbox layout  
  - Day 3: JavaScript ES6 basics, array methods  
  - Day 4: Next.js routing, Tailwind setup  
  - Day 5: Responsive design, deploy to Vercel  
  - Day 6: Accessibility + Lighthouse check  
  - Day 7: Reflection in `project.md`  

---

### Week 3–4: **Backend Basics**
- Goal: Build **Task Manager API**  
- Daily checkpoints:  
  - Day 1: Setup Express server, `/tasks` route  
  - Day 2: Connect PostgreSQL with Drizzle ORM  
  - Day 3: CRUD endpoints, test with Postman  
  - Day 4: JWT authentication  
  - Day 5: Error handling, validation, unit tests  
  - Day 6: Dockerize backend  
  - Day 7: Reflection in `project.md`  

---

### Week 5–6: **DevOps Setup**
- Goal: Dockerize and deploy apps, provision infra with Terraform  
- Daily checkpoints:  
  - Dockerize frontend + backend  
  - Deploy to Vercel & VPS  
  - Provision GCP VM + HA VPN with Terraform  
  - Reflection in `project.md`  

---

### Week 7–8: **AI Systems Integration**
- Goal: Connect LLM APIs, build **RAG pipeline**  
- Daily checkpoints:  
  - Connect GPT/Claude APIs  
  - Build vector DB + retrieval  
  - Experiment with multi-agent orchestration  
  - Reflection in `project.md`  

---

### Week 9–10: **Scaling & Monitoring**
- Goal: Add logging, metrics, CI/CD pipelines  
- Daily checkpoints:  
  - Setup Winston/Bunyan logging  
  - Prometheus + Grafana metrics  
  - GitHub Actions CI/CD  
  - Reflection in `project.md`  

---

### Week 11–12: **Capstone Project**
- Goal: Combine frontend, backend, DevOps, AI into one cohesive app  
- Daily checkpoints:  
  - Integrate all modules  
  - Deploy live  
  - Document architecture in `project.md`  
  - Share repo + write reflection blog
